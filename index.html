08主要工作最常使用哪個模型？

模型、服務平台與費用，要分開看

工具是你操作的入口；模型是實際處理任務的系統；服務通路決定模型在哪裡執行、由誰提供算力與如何計費。同一個 Qwen 或 DeepSeek 模型，可以由外部平台代管，也可以由公司自行部署。

商業閉源模型服務
例如透過供應商使用 GPT、Claude 等系列。可能採訂閱、Token 用量或企業合約計費；訂閱額度與 API 帳單不一定共用。
開放權重模型的商業代管
例如經 Databricks、OpenRouter 或其他供應商使用開放權重模型。取得模型權重與執行推論是兩回事；平台提供 GPU 與服務通常有費用，也可能提供有限的免費方案。這些平台也可能提供閉源或外部模型，不能只看平台名稱就判斷模型類型。
公司 On-prem 模型
由公司自行部署，常使用開放權重模型，但不能因此斷定全部都是開源。即使個人沒有扣款，公司仍負擔硬體、電力、維運及可能的授權費；也可能排隊或有容量限制。

「開放權重」不等於符合所有開源條件；可否商用依模型版本與授權條款。內部 Chatbot 也可能轉送外部服務，資料能否使用仍依公司核准政策。比較時看整個任務的成功率、重試次數、總耗時與成本，無需在此提供金額。

平台說明：Databricks Foundation Model APIs · OpenRouter 計費說明（2026-10-15 查閱；實際依公司合約）
